# Mobile project record

Status: preparation in progress. Populate from the project and user; unknowns are not decisions.

## Purpose and users

Product, audience, priority task, intended outcome, content and languages.

## Scope

Platforms, priority journeys/states, deliverables, exclusions and constraints.

## Direction

Selected/proposed/delegated status; references actually inspected; hierarchy,
density, typography, spacing, components, motion intent and intentional exceptions.
Keep numerical values in the native theme; link to those files here.

## Authoritative sources

Actual theme/component/asset paths, relevant Figma nodes and ownership of changes.
Record available and unavailable sources separately.

## Execution and verification

Actual build commands and environment, capture path, target devices, UX criteria,
profiling path and agreed performance criteria. Unknown or unrun checks remain so.

## Decisions and next action

Decision, date/revision, rationale, dependencies, unresolved questions and next step.
Record whether a showcase is requested; app completion uses the shared contract.
