# Toolkit contributor context

This repository supplies native design evidence tools and portable agent
instructions. It is not itself an iOS/Android app. Respect the scope and mixed
licenses in `LICENSE`, `NOTICE` and `docs/usage-rights.md`.

The runtime contract is `src/server.ts`; persistence is `src/store.ts`;
reference providers, media, recipes and bounded review packets have separate
modules. Motion recipe snippets are authored and have not all been compiled.
The Tempo Android example has recorded build/capture checks in docs/tempo-study.md.
Palette and Passage are standalone SwiftUI studies; Folio uses Expo / React Native.
Read each example README and its evidence scope before reporting native coverage.
Explicit project targets and V2 brief/review/packet artifacts separate operating
system from implementation stack. Legacy native V1 artifacts remain supported.
Figma and Rive use
external official connections and are not bundled runtime providers.

Workflow truth is `docs/workflow.md`; client installation is `docs/clients.md`;
specialist profiles and independent review requirements are in `docs/agents.md`.
Keep skill routing, documentation and runtime capabilities consistent. Preserve
observed versus authored evidence, source ownership, revision invalidation and
separate design/UX/performance completion. Do not invent successful native tests,
authenticated providers, profile measurements or editor exports.

Use Node 22.13+ (CI uses Node 24) with ffmpeg/ffprobe on PATH. `npm test` builds
TypeScript and runs the offline suite. `npm run smoke` contacts public award
providers through the real stdio server and writes ignored local artifacts.
Run installation/helper tests for changes to scripts; do not exercise them on
real user instruction files when a temporary fixture suffices.

Do not commit credentials, capture libraries, generated packets, internal research
or runtime databases. Installed workflow bundles are snapshots outside this source
tree. The installer preserves unmanaged or modified destinations and never changes
client permission or model settings. Root instruction wrappers link here; preserve
unrelated instructions in consuming app projects.

Before any authorized GitHub publication, review the study-only
labeling, license scopes/notices, content rights and publication set; run
`npm run check:publication` for label consistency and common leaks. It is not a
legal-clearance certificate. Keep internal evidence and secrets out of publication.
